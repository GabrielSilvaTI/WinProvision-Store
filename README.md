# WinProvision Store

<p align="center">
  <img src="docs/assets/winprovision-icon.png" alt="Ícone do WinProvision Store" width="220">
</p>

O **WinProvision Store** é um aplicativo para Windows que ajuda a encontrar,
instalar e organizar aplicativos de forma simples e rápida.

Além do catálogo de aplicativos, ele oferece recursos para:

- instalar vários aplicativos de uma vez;
- criar e restaurar perfis de instalação;
- atualizar aplicativos instalados;
- configurar o Microsoft Office;
- preparar o Windows com opções de provisionamento;
- executar instalações automáticas pelo modo Auto.

## Como funciona

O aplicativo carrega um catálogo atualizado de aplicativos, identifica os
programas disponíveis e usa o **WinGet** para realizar as instalações,
atualizações e demais operações.

O catálogo e os ícones são atualizados automaticamente em serviços externos,
mantendo o aplicativo leve e sempre atualizado.
