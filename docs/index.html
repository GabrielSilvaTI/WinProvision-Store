Sobre o Projeto

O WinProvision Store nasceu para resolver a fragilidade das automações convencionais de TI. Em vez de depender de uma colcha de retalhos de scripts isolados e utilitários de terceiros, o projeto unifica o catálogo de software, o deploy do Microsoft 365, a personalização de sistema e a telemetria em um único executável de alta performance.

Construído nativamente em C# .NET 10 com interface em WPF-UI (Fluent Design), o sistema opera de forma autônoma durante o ambiente de FirstLogon (via conta SYSTEM ou Administrador) sem necessitar de runtimes pré-instalados.

Notas da Versão v1.0.0

    Orquestrador Winget: Busca, instalação e atualização em tempo real integrado aos catálogos oficiais da Microsoft. Deployment do Office 365: Gerador dinâmico de configurações do Office Deployment Tool (ODT) sem intermediários. Canvas Visual de Personalização: Organização interativa de atalhos e papéis de parede com exportação Base64 autocontida. Branding OEM Customizado: Edição direta das chaves de identificação de sistema e fabricante no Registro do Windows. Sincronização via GitHub Gist: Importação e exportação de perfis JSON completos via nuvem. Telemetria e CLI Nativa: Suporte para execução silenciosa (/silent) com logs remotos via Webhook (Discord/Slack).

Execução Automatizada (CLI)

Para utilizar o WinProvision Store em rotinas Unattended ou scripts de SetupComplete.cmd, utilize a sintaxe de linha de comando gerada diretamente pela aplicação:

WinProvision.Store.exe /auto "https://gist.githubusercontent.com/.../profile.json" /silent /webhook "https://discord.com/api/webhooks/..."
